# DAYON 배포 준비

현재 준비된 구성은 **무료 서비스 기본 주소 + 데이터가 보존되는 운영 서버**입니다. 주소 자체의 비용과 서버·저장소 이용료는 별개입니다. 이 문서와 예제 파일을 저장하는 것만으로 계정이나 유료 자원이 생성되지 않습니다.

## 현재 배포 상태

외부 배포 계정은 연결되어 있지 않으며, 공개 접속 주소도 아직 발급되지 않았습니다. 이 개발 환경은 운영 호스팅 서비스가 아닙니다. 로그인 정보나 결제정보를 채팅으로 전달하지 마세요.

## Render를 사용할 경우

[Render](https://render.com/)의 기본 `onrender.com` 주소를 사용하고 Node.js 서버와 영구 디스크를 함께 구성할 수 있습니다. `deploy/render.yaml.example`은 검토용 초안입니다. 루트에 자동 인식되는 배포 파일을 두지 않았으므로, 비용과 계정을 확인한 뒤 사용할 수 있습니다.

1. 본인 소유 Render 계정에서 GitHub 저장소 `arme9610-sketch/123`을 연결합니다. 코드가 GitHub에 업로드되어 있어야 합니다.
2. 새 Node 웹 서비스를 생성하고 저장소 루트를 사용합니다. Node 버전 `24`, 빌드 명령 `npm run check`, 시작 명령 `npm start`, 상태 확인 경로 `/api/status`를 지정합니다.
3. **생성 버튼을 누르기 전에** 서버와 영구 디스크의 실제 요금 및 데이터 보존 조건을 확인합니다. 이 환경에서는 Render 공식 문서에 대한 네트워크 접근이 차단되어 최신 금액을 검증하지 않았습니다. 최종 비용은 서비스 화면에서 확인해야 합니다.
4. 서버 인스턴스는 하나만 사용합니다. 영구 디스크를 `/var/data`에 연결하고 다음 변수를 설정합니다.

   | 변수 | 값 |
   |---|---|
   | `NODE_VERSION` | `24` |
   | `NODE_ENV` | `production` |
   | `MOA_DATA_DIR` | `/var/data/dayon` |
   | `MOA_SECURE_COOKIE` | `1` |
   | `MOA_SETUP_TOKEN` | 서비스의 비밀 환경변수로 생성한 충분히 긴 무작위 값 |

   설정 키는 첫 관리자 생성에 사용합니다. 예제의 `generateValue: true`는 배포 서비스가 값을 생성하도록 요청합니다. 키를 GitHub에 저장하지 않습니다.
5. 생성 후 서비스가 실제로 발급한 HTTPS 주소로 접속합니다. 서비스 이름 `dayon-arme`는 제안값이며 실제 주소의 사용 가능 여부는 확인하지 않았습니다. 도메인을 별도로 구매할 필요는 없습니다.
6. 본인이 서비스 설정 화면에서 확인한 초기 설정 키와 원하는 아이디·비밀번호로 관리자 계정을 생성합니다. **팀 관리**에서 나머지 직원을 초대합니다.

Render 무료 웹 서버의 임시 디스크에 현재 SQLite를 저장하면 재배포 시 업무 데이터가 사라질 수 있습니다. 현재 앱으로 운영 데이터를 보존하려면 영구 디스크가 필요합니다. 서버 비용까지 무료로 운영하려면 외부 영구 데이터베이스 등을 사용하는 구성 변경과 해당 서비스 계정이 추가로 필요합니다.

## 배포 후 검증

- HTTPS로 관리자 생성·로그인·로그아웃이 되는지 확인합니다.
- 브라우저의 `Origin`과 서버가 받는 공개 `Host`가 일치해야 합니다. 임의의 전달 헤더를 신뢰하거나 CSRF 검사를 끄지 않습니다.
- 서로 다른 두 직원 계정으로 일정 등록과 채팅이 실시간 공유되는지 확인합니다. SSE 응답은 프록시에서 버퍼링하지 않도록 합니다.
- 입고 완료 및 완료 취소 시 두 직원 화면의 수량이 함께 변하는지 확인합니다.
- 테스트 업무를 등록한 뒤 서비스를 재시작해 기록이 남는지 확인합니다.
- 운영 시작 전 데이터 백업·복원 방법을 확인합니다. 현재 백업 방법은 루트 README를 참고하세요.

현재 개발 DB는 자동으로 외부 서버에 이전되지 않습니다. 실제 기록을 옮겨야 한다면 기존 서버를 중지하고 백업을 먼저 보존한 뒤 별도로 이전합니다. 배포 키, 직원 비밀번호, DB 파일은 소스 저장소에 포함하지 않습니다.
