# Dayon 업무시간 예약 운영

한국 시간 월~금 09:00~18:00. 토·일요일, 한국 공휴일·대체공휴일과 MOA_HOLIDAYS 지정일은 휴무입니다. GitHub Actions가 Render 서비스의 suspend/resume 관리 API를 호출합니다. 중지된 서버의 주소에 접속하는 것만으로 서비스가 재개되지 않게 하는 방식입니다. 데이터베이스를 삭제하거나 계정·파일을 변경하지 않습니다.

## 활성화 전 필요한 설정

1. Render 계정의 Account Settings → API Keys에서 관리 키를 생성합니다. 이 키는 다른 서비스도 관리할 수 있으므로 공유하지 않습니다. 필요한 Dayon 서비스만 있는 별도 관리 계정을 사용할 수 있다면 권한을 최소화합니다.
2. GitHub `arme9610-sketch/123` → Settings → Secrets and variables → Actions → Secrets에 `RENDER_API_KEY`를 등록합니다. 값을 코드·채팅·일반 변수에 넣지 않습니다.
3. Actions Variables에 `RENDER_SERVICE_ID`를 지정하면 해당 서비스만 대상으로 합니다. 선택 사항이며 미설정 시 키로 접근 가능한 목록에서 `https://one23-h665.onrender.com`과 일치하는 서비스를 찾습니다. URL·유형을 다시 검사하여 다른 서비스를 중지하는 것을 차단합니다.
4. 회사 자체 휴무일은 `MOA_HOLIDAYS` 변수에 쉼표로 구분한 YYYY-MM-DD 날짜를 입력합니다. Render에도 같은 값을 설정하여 반복업무의 휴일과 맞춥니다. 새로 발표된 임시공휴일은 추가해야 합니다.
5. Actions → Dayon office hours → Run workflow로 수동 검증합니다. 실행 당시가 영업시간이면 시작·준비 확인, 그 외에는 중지를 수행하므로 업무시간 밖에서는 사이트 접속과 채팅 알림이 중단됩니다. 실제 외부 DB가 Neon인지, 서버 로컬 SQLite에 업무자료가 없는지 먼저 확인해야 합니다. Free 서버의 재시작 시 로컬 파일은 보존되지 않습니다.
6. 수동 실행이 성공하고 Render Events에서 동작을 확인한 뒤 Actions Variables의 `DAYON_SCHEDULE_ENABLED`를 `true`로 지정합니다. 자동 예약은 이 변수가 없으면 작동하지 않습니다. 끄려면 `false`로 지정하고 필요 시 Render에서 수동 재개합니다.

## 예약과 한계

- GitHub UTC 00:00/09:00 = 한국 09:00/18:00에 매일 현재 영업 여부를 확인합니다. 주말·공휴일 오전에도 중지 상태를 확인합니다.
- 평일에는 각각 5·10·15·20분 후 재시도하여 일시적인 API 오류와 기동 지연을 완화합니다. 오전 준비 확인은 09:20까지 수행하여 Free 서버가 15분 미사용으로 다시 잠드는 것을 줄입니다.
- 실제 실행 시각을 기준으로 판단하므로 오전 실행이 저녁으로 지연되어도 야간에 서버를 켜지 않습니다. 서비스 시작 요청 후 `/api/status` 응답도 확인합니다.
- GitHub 예약은 최선형 실행이며 지연·누락될 수 있습니다. 09:20 준비 및 18:00 중지를 보장하는 타이머가 아닙니다. 시간 준수가 필수라면 신뢰할 수 있는 외부 예약 서비스가 필요합니다.
- 공개 GitHub 저장소의 예약은 60일간 저장소 활동이 없으면 자동 비활성화될 수 있습니다. 관리자가 Actions 실행 내역과 실패 알림을 확인하고 필요하면 재활성화해야 합니다.
- 비공개 저장소의 Actions 실행은 GitHub의 무료 실행시간 한도를 소모할 수 있습니다. 부족하면 예약 실행이 중단될 수 있으므로 Billing/Usage를 확인합니다.
- Render Free는 업무시간 중에도 15분 미사용 시 잠들 수 있습니다. 이 예약은 하루 종일 깨어 있도록 인위적으로 요청하는 방식이 아닙니다. 항상 즉시 응답해야 한다면 서버 요금제를 검토합니다.
- Render 중지 후 앱의 DB 요청이 사라지면 Neon Free는 약 5분 뒤 절전할 수 있습니다. Neon 콘솔·다른 앱의 DB 연결이 남으면 절전이 지연됩니다. 이 예약은 Neon의 저장 데이터나 복원 이력을 삭제하지 않습니다.

## 검증 상태

로컬 테스트는 한국 시간 09:00 시작·18:00 종료, 주말·공휴일 제외, 지연 실행의 야간 재개 방지, 잘못된 서비스 조작 차단, API 접근 거부와 비밀값 누락 처리를 확인합니다. 실제 Render 키로 수동 실행을 완료하기 전에는 운영 자동화가 활성화되었다고 판단하지 않습니다.
